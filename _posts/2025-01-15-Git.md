# CLI를 사용하는 이유
## CLI : Command Line Interface
- 명령어를 통한 상호작용 인터페이스
### 효과
1. 효율성
    - CLI는 키보드만으로 모든 작업을 수행할 수 있으며 메모리와 CPU 사용량이 적어 저사양 시스템어서도 효율적으로 동작한다.
2. 정밀한 제어
    - 특정 프로그램이나 시스템의 세부 설정을 보다 정밀하게 제어할 수 있다.
3. 표준성
    - CLI 명령어는 대부분의Unix 운영체제 기반 시스템에서 동일하게 작동하여 여러 환경에서 적용할 수 있다.

# 중요 Point!
- 내가 어디 있는지(경로)를 알고 있을 것
### 절대 경로
- Root 디렉토리부터 목적 지점까지 거치는 모든 경로를 전부 작성한 것
- ex) C:/Users/ssafy/Desktop

### 상대 경로
- 현재 작업하고 있는 디렉토리를 기준으로 계산된 상대적 위치를 작성한 것
- ex) 현재 작업 디렉토리가 C:/Users일 때 -> ssafy/Desktop
